What does the free check look at?

Twelve things, all of them visible in the page source or in files every site already publishes. Each one returns pass, warn or fail with the actual value found, so you can confirm it by viewing source. Nothing here is a guess about ranking, and nothing is scored on a curve.

Indexability and identity

No noindex, a title of 15–65 characters, a description of 50–160, one H1 only, a self-referencing canonical.

Machine-readable facts

JSON-LD that parses and declares a type, plus the answer-block and question-heading pattern language models quote from.

Freshness

A visible date, or a dateModified in the markup, and whether it is recent enough to be worth citing.

Crawl access

robots.txt checked per user-agent (GPTBot, ClaudeBot, PerplexityBot, Google-Extended, CCBot, meta-externalagent), llms.txt, and a sitemap with URLs in it.

How is this different from the paid audit?

The free check reads one page and stops at the HTML. The audit adds what a fetch cannot see: Search Console impressions and queries per page, Core Web Vitals from a real browser, redirect chains, duplicate clusters, thin pages across the whole site, and a written order of work with before and after numbers.

We publish that difference rather than blur it. The twelve checks are the same rules we run as a gate on our own sites, so they are worth fixing; they are not the whole job.

Is anything about my site stored?

No copy of the page is kept. The scan result is cached for six hours keyed by a hash of the URL, so the same check does not hit your server twice. The rate limit is a counter, not a log: it stores a hash and an expiry, never your IP address. If you ask for the report by email, we keep that email with the URL you asked about, the same way a contact form would.

How do I get the full report?

Run the free check first. At the end of the results you can ask for the report by email: we scan the homepage plus up to four URLs from your sitemap, list what failed on each one, and put the fixes in the order we would do them.

It is one email, no list, and a reply reaches a person. Checked on 2026-10-19.
